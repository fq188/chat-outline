# 隐私政策 · Privacy Policy

**生效日期：2026-10-19**

## 中文

「对话目录 · Chat Outline」是一款完全在本地运行的浏览器扩展。

- **不收集任何数据**：扩展没有任何网络请求，不追踪、不上报、不传输任何信息到任何服务器。
- **不读取账号数据**：扩展只在当前页面内识别对话消息的文本结构，用于生成目录；不读取、不保存你的登录状态、Cookie 或任何账号信息。
- **本地存储**：扩展仅使用浏览器自带的 `chrome.storage.local` 保存你的界面偏好（面板开/关、左右侧、是否显示回答）和你手动填写的 CSS 选择器。这些数据只存在你自己的浏览器里，卸载扩展即删除。
- **导出功能**：「导出 Markdown」只在你主动点击时，把当前页面已显示的对话内容保存为本地文件，文件只写到你自己的电脑上。
- **无第三方**：不接入任何第三方服务、分析工具或广告。

如有疑问，请在 GitHub 提 issue：<https://github.com/fq188/chat-outline/issues>

## English

**Chat Outline** runs entirely on your device.

- **No data collection**: the extension makes no network requests. Nothing is tracked, reported, or transmitted anywhere.
- **No account data**: it only reads the text structure of chat messages on the current page to build the outline. It never touches your login state, cookies, or account information.
- **Local storage only**: it uses `chrome.storage.local` solely to remember your UI preferences (panel open/closed, side, show-answers toggle) and any CSS selectors you enter manually. This data stays in your browser and is removed on uninstall.
- **Export**: "Export Markdown" only runs when you click it, saving the currently visible conversation to a local file on your own machine.
- **No third parties**: no analytics, no ads, no external services.

Questions? Open an issue at <https://github.com/fq188/chat-outline/issues>
